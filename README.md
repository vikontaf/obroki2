# Оброки

Лёгкое Android-приложение для учёта ежемесячных платежей: отметить оплату → при необходимости клон на следующий месяц (с опциональным долгом).

**Стек:** Kotlin, одна Activity, Jetpack Compose, Room, DataStore Preferences. Без сети и аккаунтов.

## Открыть и запустить в Android Studio

1. Установите [Android Studio](https://developer.android.com/studio) (Ladybug / 2024.2+ или новее) с Android SDK 35 и JDK 17.
2. **File → Open** → выберите корень этого репозитория (папка с `settings.gradle.kts`).
3. Дождитесь синхронизации Gradle (Studio скачает зависимости).
4. Создайте эмулятор (API 26+) или подключите устройство с отладкой по USB.
5. Нажмите **Run** ▶ на конфигурацию `app`.

Из командной строки (если SDK настроен):

```bash
./gradlew :app:assembleDebug
./gradlew :app:installDebug
```

Юнит-тесты доменной логики (клон, дедуп, проекция сумм, цвета):

```bash
./gradlew :app:testDebugUnitTest
```

## Что умеет MVP

- Один экран: заголовок «Оброки» + календарь | сумма к оплате | меню
- Список платежей по эффективной дате; создание / правка суммы и долга / удаление
- Короткий tap: оплачен ↔ неоплачен; клон на следующий месяц с дедупом и rollover дня
- Опциональный долг: при `debt' ≤ 0` клон не создаётся
- Очистка погашенных (кроме текущего месяца), туториал, цикл темы тёмная → светлая → системная, заглушка доната
- Календарь текущего месяца; сумма к оплате за 5 периодов с проекцией будущих месяцев
- Цвета строк: оплачен зелёный, просрочен красный, &lt;7 дней жёлтый
